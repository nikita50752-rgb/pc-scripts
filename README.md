# Скрипты обслуживания ПК (Windows 10/11)

Три простых PowerShell-скрипта: навести порядок в «Загрузках», найти одинаковые файлы и присматривать, не завёлся ли на компьютере майнер или другой вирус.
Работают без прав администратора и без установки сторонних программ. **Ничего не удаляют безвозвратно** — только перемещают или отправляют в Корзину (кроме старых временных файлов в `AppData\Local\Temp`).

| Скрипт | Что делает |
|---|---|
| `Уборка.ps1` | Раскладывает файлы из «Загрузок» по папкам (Документы, Изображения, Видео, Архивы, Установщики…), установщики старше 30 дней — в Корзину, чистит временные файлы старше 7 дней. `-Проверка` — только показать, что будет сделано |
| `Дубликаты.ps1` | Ищет одинаковые по содержимому файлы в выбранной папке, показывает таблицу; выбранные копии уходят в Корзину после подтверждения. Системные папки и папки программ не трогает |
| `Сторож.ps1` | Проверяет признаки заражения: выключенный Защитник, новые исключения в Защитнике, папки со случайными именами в ProgramData, новые неподписанные программы в автозагрузке, планировщике и службах. При тревоге — уведомление Windows и отчёт. Ничего не меняет |

## Установка

1. Скачайте репозиторий: зелёная кнопка **Code → Download ZIP**, распакуйте в удобную папку (например, `Документы\Скрипты`).
2. Откройте PowerShell в этой папке и выполните:

```powershell
powershell -ExecutionPolicy Bypass -File .\Установить.ps1
```

Появятся ярлыки «Уборка», «Найти дубликаты», «Сторож» на рабочем столе, а Уборка и Сторож будут запускаться сами по воскресеньям.
Удалить ярлыки и задачи: `powershell -ExecutionPolicy Bypass -File .\Установить.ps1 -Удалить`

## Запуск вручную

```powershell
powershell -ExecutionPolicy Bypass -File .\Уборка.ps1 -Проверка   # посмотреть без изменений
powershell -ExecutionPolicy Bypass -File .\Дубликаты.ps1 -Папка "D:\Фото" -ТолькоСписок
powershell -ExecutionPolicy Bypass -File .\Сторож.ps1
```

## Важно

- «Сторож» не заменяет антивирус — он подсказывает, когда стоит запустить полную проверку.
- Файлы сохранены в UTF-8 с BOM — это нужно Windows PowerShell 5.1 для русских букв. Если редактируете, сохраняйте так же.
- Перед запуском любого скрипта из интернета загляните в него — эти открыты и прокомментированы.
